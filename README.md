# digital-gantt-chat / snake site 現場工程表

一つの案件・一つの工程データを、今日の現場、ガントチャート、ネットワーク図、工程一覧で共有する建設工程管理アプリです。各画面は同じ `tasks` レコードと同じ日程計算結果を表示し、表示ごとの複製データを持ちません。

## 現場での主な流れ

1. 責任者が案件を作成し、標準工程テンプレートの使用有無を選びます。
2. 責任者が編集者・閲覧者をメールアドレス指定で招待します。
3. 現場担当者はスマートフォンで「今日」を開き、着手・進捗・完了と写真を報告します。
4. 監督は遅延、次の工程、発注・承認・検査・是正を確認します。
5. 責任者は変更案を確認してから日程を反映し、工程版として確定します。

工程は「＋ 工程」または各表示の工程タップから同じ編集画面を開きます。完了報告もガントと「今日」で同じ報告画面を使います。閲覧者には変更操作を表示せず、DB側でも更新を拒否します。

## 機能

- Supabase Auth、Postgres、Realtime、案件単位RLS
- 責任者・編集者・閲覧者と期限付き招待リンク／QR
- 予定日、実績日、進捗率、残日数、遅延理由、検査状態、次アクション
- 進捗／完了報告、コメント、メンション、写真・PDF（非公開Storage、1ファイル10MB）
- ガントの横スクロール、日幅変更、基準／現在／実績／進捗表示
- 建築ネットワーク（番号付きイベント・工程矢線・ダミー線）と工程カード表示
- クリティカル工程、EST/EFT/LST/LFT、TF/FF、前後関係一覧、共有手動配置
- 工程表上の前工程・後続工程表示、天候休工日を含む変更影響の確認と承認
- Excel／CSV／TSV（PDF読取結果）の候補取込、エラー確認後の一括追加
- ネットワーク工程のドラッグ微調整と、案件メンバー間で共有される配置保存
- 発注、納品、図面、承認、検査、是正などの管理項目
- 当初工程と確定版、版比較、安全な復元前バックアップ
- 変更履歴と対象・操作・キーワード絞り込み
- アプリ内通知と通知設定（外部メール／LINEは別途配信設定が必要）
- A3/A4印刷・PDF、UTF-8 BOM CSV、Excel出力
- PWAのアプリシェルキャッシュ、利用者別の案件キャッシュ、オフライン進捗キュー
- 競合時は自動上書きせず、端末側とサーバー側を比較して再編集または破棄

## 技術とセキュリティ

- フロントエンド: Vanilla HTML / CSS / ES Modules（GitHub Pages）
- 認証・DB・Realtime・Storage・RLS: Supabase
- 競合対策: `projects.revision` / `tasks.version` の楽観的ロック
- 履歴: DBトリガーによる監査ログ
- Excel: vendored SheetJS CE 0.20.3
- QR: vendored qrcode-generator 2.0.4

ブラウザに保存するのはSupabaseセッション、表示設定、利用者IDで分離したオフラインキャッシュだけです。アプリ独自パスワード、招待トークンの平文、`service_role`キーは保存しません。Storageは非公開で、案件メンバーだけが短時間の署名URLを取得します。Service WorkerはSupabase/API応答をキャッシュしません。

## セットアップ

共同編集にはGitHub PagesだけでなくSupabaseが必要です。最初の導入、既存環境の更新、Storage、招待メール、認証URL、公開手順は [SETUP.md](SETUP.md) を参照してください。

```sh
npm run check
npm test
python3 -m http.server 4173
```

## 既存データの移行

ログインメールと一致する旧ローカルアカウントの案件（`snake_projects_v1`）と旧ネットワーク工程表（`snake_network_schedule_v1`）を検出し、共有DBへコピーできます。元の `localStorage` は削除しません。旧アプリのパスワードハッシュは移行せず、Supabase Authでアカウントを作り直します。

## Excel／バーチャート工程表からの取込

案件画面の「工程を取り込む」から `.xlsx` / `.xlsm` / `.xls` / `.csv` / `.tsv` を選択できます。Excelは `03作業リスト` を優先し、作業名・開始日または所要日数を持つ表を候補化します。PDFそのものをブラウザで確定データへ変換せず、`bar_pdf_reader.py` が出力したTSV／CSVを取り込みます。

候補は記号重複、不明な前工程、日付逆転、読取座標の「棟・階」混入を検査します。問題のない行だけを人が選択して追加し、既存工程は上書きしません。取り込み後は通常の工程編集とネットワーク図の「配置を調整」で修正できます。

## ブランチ

- `main`: 既存ガント
- `feature/field-share`: 調査時点では `main` と同一
- `feature/network-schedule`: 独立したネットワーク工程表
- `feature/collaborative-schedule`: 共同編集・現場運用・統合表示
- `feature/hybrid-network-builder`: Excel／読取結果の確認取込・手動ネットワーク配置
